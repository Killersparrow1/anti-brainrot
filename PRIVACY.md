# Privacy Policy

**Last Updated:** 2024-01-15

**Anti-BrainRot** is a **fully offline** application. This privacy policy reflects our commitment to **zero data collection**.

## Our Promise

**We collect absolutely nothing. No analytics. No crash reports. No tracking. No accounts. No cloud sync. Ever.**

## Information We Collect

### Data You Provide (Stored Locally Only)
- **Preferences**: Daily limits, notification settings, theme preferences
- **Onboarding Answers**: Your responses to the initial assessment (stored locally)

### Automatically Collected Data (Stored Locally Only)
- **Reels/Shorts Count**: Number of reels watched per app, per hour (core functionality)
- **Usage Statistics**: App open/close times, feature interactions
- **Device Information**: Android version, device model, language, timezone (for compatibility only)

### Data We NEVER Collect
- ❌ **Personal Content**: Messages, photos, videos, contacts
- ❌ **Browsing History**: Outside of supported social media apps
- ❌ **Keystrokes**: Passwords, search queries, typed text
- ❌ **Location**: GPS coordinates or precise location
- ❌ **Microphone/Camera**: Audio or video recordings
- ❌ **Account Information**: No login, no email, no profile
- ❌ **Crash Logs**: No crash reporting service
- ❌ **Performance Metrics**: No telemetry
- ❌ **Advertising IDs**: No ad tracking

## How We Use Your Data

### Core Functionality (All Local)
- Count reels/shorts in real-time using Accessibility Service
- Display floating bubble overlay with live count
- Provide daily/weekly statistics and charts
- Enforce user-set daily limits
- Send local notifications (milestones, warnings)

### No External Processing
- No cloud sync
- No server-side analysis
- No A/B testing
- No external crash reporting
- No third-party analytics

## Data Storage & Retention

- **100% Local Storage**: All data stored in Room/SQLite database on your device
- **No Cloud Sync**: Zero network transmission
- **Retention**: Data kept until app uninstall or manual clear in settings
- **Your Device, Your Data**: Full control, no remote access

## Your Rights

Since we collect no personal data and transmit nothing:
- **Access**: All your data is visible in-app
- **Rectify**: Edit preferences in settings
- **Erase**: Uninstall app or use "Clear Data" in settings
- **Portability**: Export data via in-app feature (planned)
- **No Consent Needed**: No data processing requiring consent

## Children's Privacy

Anti-BrainRot is safe for all ages. We collect **zero** data from anyone.

## Security

- **No Network Traffic**: Zero attack surface for data interception
- **Local Database**: Room/SQLite (Android's built-in encryption)
- **No API Keys**: None needed, no network calls
- **No Sensitive Data in Logs**: Debug logs disabled in release
- **Open Source**: Full code auditability at github.com/yourusername/anti-brainrot

## International Transfers

**Not applicable** - no data leaves your device.
